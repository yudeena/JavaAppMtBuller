# Mt Buller Resort Booking System

This is a JavaFX-based desktop application simulating a booking and information system for a fictional Mt Buller Resort. Developed for the course **COSC2511 – Introduction to Programming A** at **RMIT University**, the project demonstrates core programming concepts, visual interface design, and modular problem-solving.

**Top-performing project in the cohort** — selected by the tutor for presentation to a panel of employers.

---

## Features

- **Accommodation Booking**  
  Users can book resort services with dynamic selection, user prompts, and cost calculation.

- **Visual Interface**  
  Built using JavaFX, featuring images, structured menus, and navigable interface components.

- **Resort Information Display**  
  Sections include resort details, weather information, FAQs, and contact details.

- **Input Validation**  
  Ensures smooth user interaction with consistent error handling and feedback.

- **Modular Architecture**  
  Clean separation of logic into reusable classes and methods for ease of maintenance.
